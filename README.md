# ฮักเนอร์สซิ่งโฮม — เว็บไซต์ประชาสัมพันธ์ + ระบบบริหารจัดการข้อมูล

โครงสร้างเริ่มต้น (starter code) สำหรับศูนย์ดูแลผู้สูงอายุ ประกอบด้วย
เว็บไซต์ประชาสัมพันธ์สาธารณะ และระบบหลังบ้านสำหรับเจ้าหน้าที่/ผู้ดูแลระบบ
พร้อมใช้ต่อยอดตามสไลด์เทคโนโลยีที่กำหนด (HTML/CSS/JS/PHP/MySQL)

## ภาษาและเทคโนโลยีที่ใช้ (ตรงตามที่ระบุในโจทย์)

| เทคโนโลยี | ใช้ทำอะไรในโปรเจกต์นี้ |
|---|---|
| **HTML5** | โครงสร้างทุกหน้า ฝังอยู่ในไฟล์ `.php` (PHP พิมพ์ HTML ออกมา) |
| **CSS3** | `assets/css/style.css` (หน้าเว็บประชาสัมพันธ์) และ `assets/css/admin.css` (ระบบหลังบ้าน) — Layout, สี, ฟอนต์, Responsive |
| **JavaScript** | `assets/js/main.js` — เปิด/ปิดเมนูมือถือ, ยืนยันก่อนลบข้อมูล ฯลฯ. หน้า dashboard ใช้ Chart.js (โหลดผ่าน CDN) วาดกราฟโดนัท |
| **PHP** | ทุกไฟล์ `.php` — ดึง/บันทึกข้อมูล, ตรวจสอบฟอร์ม, ระบบ login/session, สิทธิ์การเข้าถึง |
| **MySQL** | `database/schema.sql` — ฐานข้อมูลเชิงสัมพันธ์ 8 ตาราง เชื่อมต่อผ่าน PDO |
| **Apache/XAMPP** | สภาพแวดล้อมรันโปรเจกต์นี้ระหว่างพัฒนา (วางโฟลเดอร์ใน `htdocs/`) |
| **VS Code / Figma / Canva** | เครื่องมือเขียนโค้ด / ออกแบบ UI ก่อนพัฒนา / ทำภาพกราฟิกประชาสัมพันธ์ (ไม่ใช่ส่วนของโค้ด) |

> โค้ดทั้งหมดเป็น PHP ฝั่งเซิร์ฟเวอร์แบบ procedural (ไม่ใช้เฟรมเวิร์ก) เพื่อให้ตรงกับ
> เทคโนโลยีที่ระบุไว้ และง่ายต่อการอธิบาย/สอบในบริบทของโปรเจกต์นักศึกษา

## โครงสร้างไฟล์

```
hugnursinghome/

│   ├── news.php                 ข่าวสารและกิจกรรม
│   ├── gallery.php              แกลเลอรีภาพ

│       # ชื่อตาราง/ฟิลด์ตามหัวข้อ (โครงสร้าง CRUD เหมือนกันทุกหน้า)

│   ├── header.php / footer.php  ส่วนหัว/ท้ายของเว็บประชาสัมพันธ์
│   └── admin_sidebar.php        เมนูด้านซ้ายของระบบหลังบ้าน
│
├── assets/
│   ├── css/style.css            ดีไซน์เว็บประชาสัมพันธ์
│   ├── css/admin.css            ดีไซน์ระบบหลังบ้าน
│   ├── js/main.js
│   └── images/                  วางรูปภาพจริงตรงนี้
│
└── database/
    └── schema.sql               คำสั่งสร้างฐานข้อมูลและตารางทั้งหมด
```

## แนวคิดการออกแบบ (Design)

- **โทนสี**: เขียว (#0F4C36 / #1B9E6F), พื้นหลัง (#F4F7F5), ไฮไลต์ชมพู (#E05572)
  เป็นพื้นหลังให้ความรู้สึกอบอุ่น, ส้มอำพัน (#E0A458) เป็นสีเน้นสำหรับปุ่มและจุดสำคัญ
- **ตัวอักษร**: หัวข้อใช้ **Prompt** เนื้อหาใช้ **Noto Sans Thai** (ชุดเดียวกับ `1.html`)
- **หน้าเว็บประชาสัมพันธ์**: เน้นความอบอุ่น น่าเชื่อถือ ไม่ใช้การ์ดเงาซ้ำ ๆ
  ใช้เส้นบาง (hairline) แบ่งส่วนแทน
- **ระบบหลังบ้าน**: แถบเมนูซ้ายสีเขียวเข้มให้ความรู้สึกเป็นระบบงานจริง
  พื้นที่ทำงานสีอ่อนอ่านง่าย ใช้ป้ายสถานะ (badge) สื่อความหมายชัดเจน

## ตารางฐานข้อมูลหลัก (`database/schema.sql`)

1. `users` — บัญชีผู้ใช้ระบบหลังบ้าน (admin/staff)
2. `residents` — ข้อมูลผู้สูงอายุ/ผู้รับบริการ
3. `staff` — ข้อมูลพนักงาน
4. `services` — บริการที่แสดงหน้าเว็บ
5. `service_records` — บันทึกการให้บริการรายวัน
6. `news` — ข่าวสาร/กิจกรรม/ประกาศ
7. `gallery` — รูปภาพประชาสัมพันธ์
8. `contact_messages` — ข้อความจากแบบฟอร์มติดต่อ

## ฐานข้อมูล (PostgreSQL บน Render)

1. คัดลอก `includes/db.config.example.php` เป็น `includes/db.config.php` แล้วใส่ค่าจาก `Data.txt` (External host + รหัสผ่าน)
2. ต้องเปิดใช้ PHP extension **pdo_pgsql** (ไม่ใช้ MySQL)
3. สร้างตารางและข้อมูลตั้งต้น:

```bash
php database/setup.php
```

4. เข้าระบบแอดมิน: **admin** / **Admin@1234**

ไฟล์ `database/schema.sql` เป็น MySQL เก่า — ใช้ `database/schema.postgresql.sql` แทน

## รันดู UI บนเครื่อง (PHP built-in server)

```bash
php -S localhost:8080 router.php
```

- หน้าแรก: `http://localhost:8080/public/index.php` หรือ `http://localhost:8080/`
- แอดมิน: `http://localhost:8080/admin/login.php`

## ความปลอดภัยที่ใส่ไว้ในโครงสร้างนี้

- ใช้ **PDO Prepared Statements** ทุกจุดที่รับ input จากผู้ใช้ (ป้องกัน SQL Injection)
- ใช้ **`password_hash()` / `password_verify()`** สำหรับรหัสผ่าน (ไม่เก็บ plain text)
- ใช้ **`htmlspecialchars()`** ทุกจุดที่แสดงข้อมูลจากฐานข้อมูลกลับไปที่หน้าเว็บ (ป้องกัน XSS)
- ใช้ **`session_regenerate_id()`** หลัง login (ป้องกัน session fixation)
- หน้า `admin/*` ทุกหน้า (ยกเว้น login.php) ต้อง `require_once auth_check.php`

## สิ่งที่ควรทำต่อ (ยังไม่รวมในโค้ดตั้งต้นนี้)

- หน้า CRUD สำหรับ พนักงาน / บริการ / กิจกรรม-ข่าวสาร / แกลเลอรี (โครงเดียวกับ `manage_residents.php`)
- ระบบอัปโหลดไฟล์รูปภาพจริง (เก็บไฟล์ + path ลงตาราง `gallery`)
- ระบบสิทธิ์การเข้าถึงแบบละเอียด (เช่น staff แก้ไขได้แต่ลบไม่ได้)
- หน้า "รายงาน" แบบ export เป็น PDF/Excel
